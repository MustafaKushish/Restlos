Kassenbon fotografieren, Restlos erinnert vor dem Ablaufen und kocht mit dir die Reste.

📲 In Chrome öffnen und installieren

In Chrome erscheint dann der Knopf Jetzt installieren.

  1. Oben rechts auf ⋮ (oder unten auf ☰) tippen.
  2. „App installieren“ oder „Zum Startbildschirm“ wählen.
Lieber in Chrome öffnen
  1. Unten auf Teilen tippen (□↑).
  2. „Zum Home-Bildschirm“ wählen.
  3. Oben rechts Hinzufügen tippen. Fertig!
⬇️
  1. Oben rechts auf ··· tippen.
  2. „In Safari öffnen“ (bzw. „Im Browser öffnen“) wählen.
  3. Dort Teilen → Zum Home-Bildschirm.
⬆️

Restlos ist installiert 🎉
Du findest es jetzt auf deinem Startbildschirm.

Erst im Browser ausprobieren
  • 📸Einkauf in Sekunden erfasst, ohne Tippen
  • ⏰Erinnerung, bevor etwas schlecht wird
  • 🍳Rezepte aus dem, was noch da ist
  • 🔒Kostenlos, ohne Anmeldung, Daten bleiben auf dem Handy

Restlos ist eine Web-App: kein App Store, kein Konto, kein Download von mehreren MB. Funktioniert auch offline.
